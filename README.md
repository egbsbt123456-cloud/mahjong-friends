# Mahjong Friends · 麻将

四位好友的在线广东麻将牌桌。房主建桌后自己定规则：牌组、吃碰杠、自摸 / 点炮 / 抢杠胡、鬼牌、能胡的牌型和每步限时。没有积分、番数和筹码，先胡的人赢；牌墙摸完算平局。经典麻将桌布局：绿色桌面铺满屏幕，四家的牌和牌河朝桌心摆放，整桌按屏幕大小缩放。手机进入牌局时点一下进入全屏并尽量锁定横屏（iPhone Safari 不支持网页全屏，按普通页面显示）；竖屏也能玩。从桌游平台中独立整理，只包含麻将和它需要的账号服务。

## 本地运行

需要 Node.js 24 和 pnpm 10.34.9。项目包含原生 SQLite 依赖，安装时允许其构建脚本运行。

```sh
pnpm install --frozen-lockfile
```

把 `.env.example` 复制为 `.env`，然后：

```sh
pnpm db:migrate
pnpm dev
```

打开 http://localhost:5190 。后端只监听本机 3020 端口。四位玩家各自注册 / 登录；房主建桌并分享 10 位房间码，四人到齐、全部准备即开局。测试多个账号请使用不同浏览器或隐私窗口，普通标签页会共用登录 Cookie。

## 规则（gd-1.0）

完整规则见 [docs/rules.md](docs/rules.md)，页面上的「？规则」按钮里有简要说明。要点：

- 只限 4 人。字牌、花牌两个开关决定牌组：关字牌 108 张（万条筒），开字牌 136 张，再开花牌 144 张。花牌只亮出补牌，不影响胡牌。
- 房主可分别开关：吃、碰、明杠、暗杠、补杠；自摸胡、点炮胡、抢杠胡（只能抢补杠）；鬼牌（无鬼 / 红中鬼 / 翻鬼）；鸡胡、平胡、碰碰胡、七小对、十三幺、清一色、混一色、大三元、小三元、大四喜、小四喜、天胡、地胡；每步 15 / 30 / 60 秒。开关之间互相约束，不合法的组合不能保存。
- 鬼牌：手里的鬼胡牌时可当任意牌；可以按本身牌面吃碰杠，但不能冒充别的牌；4 张鬼不能暗杠，没有四鬼直接胡。打出去的鬼就是普通牌。
- 别人出牌后最多 10 秒响应：胡 > 碰 / 杠 > 吃，只能吃上家；多人胡只算离出牌者最近的一位。过胡后到自己下次摸牌前不能胡别人的牌。杠后从牌尾补牌，杠上开花算自摸。
- 第一局随机定庄；庄家胡连庄，别人胡下家坐庄，流局庄家不变。
- 胜负：自摸、点炮、抢杠胡都是胡牌者胜、其他三家负；流局平局。所有开启的牌型地位相同，只用来判定能不能胡和在结束画面显示。
- 出牌超时进入托管：只打刚摸到的牌，一律不吃碰杠胡，点「我回来了」才收回（刷新不算）。响应超时只算「过」。四家都托管 60 秒后关闭房间，本局作废。
- 没有积分、排行榜、观战、匹配、人机或同屏模式。

## 联机行为

服务器持有完整牌局（含牌墙顺序），按座位单独生成视图：只有自己的手牌和能做的操作；别人只看到手牌张数、吃碰杠、花牌和牌河，暗杠显示牌背；牌墙只下发剩余张数。所有操作带请求编号与版本号，同一请求重试不会重复执行；SQLite 事务防止并发冲突。客户端约每 1.2 秒同步一次。服务重启后牌局原样恢复，停机前设下的倒计时至少顺延到启动后 15 秒，避免停机期间所有人被判超时。

房间自动清理：等待中的房间 30 分钟无操作且无人开着页面、或 1 小时无操作即取消；已取消的房间 1 天后删除。进行中的对局有计时和托管，会自己结束。

## 检查与构建

```sh
pnpm typecheck
pnpm test
pnpm build
```

`pnpm test` 覆盖：牌组与设置约束、发牌补花翻鬼、三种胡牌牌形与 13 种牌型、鬼牌各种用法、吃碰杠胡优先级与多人胡、抢杠、过胡、流局、连庄换庄、超时托管与「我回来了」、四家托管作废、隐藏信息、随机打 1000 局检查牌数守恒；以及账号与房间权限、请求幂等、版本冲突、重启顺延、房间清理。

前端产物位于 `apps/web/dist`，后端产物位于 `apps/server/dist`。没有离线单文件版：牌局必须由服务器裁决。

## 上线

见 [docs/deployment.md](docs/deployment.md)。生产环境须配置自己的 HTTPS 域名、WEB_ORIGIN 和持久数据库位置。仓库不包含真实域名配置、账号、数据库、Cookie、SSH 密码或生产日志；`.env.example` 仅是本地示例。

这是独立发行版，数据库从迁移 1 开始，**不要把其它平台的数据库直接放进来**。账号是基础用户名密码登录，没有找回密码、邮箱验证或管理后台。

## 源码结构

- `apps/web`：Vue 牌桌页面（`src/pages/MahjongPlay.vue`）、SVG 牌面（`src/mahjong-tiles.ts`）、规则弹窗、账号界面、图标。
- `apps/server`：Fastify 账号和好友牌桌 API、计时与托管、房间清理、SQLite 持久化与测试。
- `packages/game-core`：纯规则引擎（`mahjong-gd-engine.cjs`，随机数从外部注入，返回新状态）。
- `packages/contracts`：房间视图类型。
